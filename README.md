Senior Software Engineer with a long track record building business software on the .NET ecosystem — from back-office APIs to web, desktop and mobile clients.

Most of my professional work lives in **private repositories** for organizations and companies, so what you see here is only a small part of it: client work, side projects and the academic projects that show how I got here.

### 💼 What I do

- Design and build **backend services and REST APIs** with ASP.NET Core
- Develop **web apps with Blazor** (WebAssembly & Server) and ASP.NET MVC
- Ship **cross-platform mobile/desktop apps with .NET MAUI**
- Maintain and evolve **WinForms** line-of-business applications
- Model relational data with **Entity Framework Core** and SQL Server
- Work end to end: requirements, data modeling, implementation, deployment and maintenance
